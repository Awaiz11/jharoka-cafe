# Jharoka — Coffee & Kitchen (concept)

A concept website for a specialty café on M.M. Alam Road, Gulberg, Lahore.
Designed and built by NexaFlow with Next.js.

- Menu with tabs and PKR prices
- Table reservations sent to WhatsApp
- Colours and patterns taken from Lahore's Kashi tilework

```bash
npm install
npm run dev
```

All text, prices and photos are in `components/data.ts`, so the site can be adapted for a new café quickly.
